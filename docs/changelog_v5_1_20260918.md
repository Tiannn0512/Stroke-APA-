## 0. 课题与纪律（迁移后仍然全部有效）

**假说链（唯一主线，不增添任何额外验证想法）**：
卒中 → 星形胶质细胞 APA 调控子改变 → 特定 mRNA 的 APA 改变 → 该 mRNA 是否终足富集 → 缩短区是否包含影响其转运的定位位点 → 结论只到 **"altered localization potential（定位潜能改变）"**。

**纪律红线（附 A，违反即输出无效）**：
1. 全文不得声称已证明实际转运；RiboTag/TRAP 一律表述为"转译组 proxy"。
2. 冻结顺序不可逆：P1-01 astrocyte 定义已冻结；Gate G2 阈值 ≥100 已预注册；P4-03 evidence class 规则须在判定前 commit。
3. 三级表述：L1 可写"调控"，L2 只写"结合证据一致"，L3 只写"预测相关"，禁止越级。
4. 禁止合成数值分数；evidence class 为可枚举判定。
5. 负结果照登，不得静默删除。
6. GSE286075 无 FASTQ，禁止任何 APA 定量。

## 6. 集群迁移注意事项

### 6.1 自动消失的坑（本机特有，集群可忘掉）
MSYS 路径转换、/d/ vs /mnt/d/、WSL 内存竞争与 vmmem 残留、9p/NTFS 慢通道、STAR FIFO on NTFS、C 盘 swap.vhdx、pydeseq2 与 STAR 抢内存的窗口互斥。

### 6.2 必须带上的坑（工具/数据语义，与平台无关）
1. **DaPars2 用补丁版源码**（空覆盖返回 'Na','Na','Na'）；若集群重装官方版必须重打补丁（对照 .bak_20260918 diff）。
2. depth 文件**无表头**（`sample<TAB>depth` 12 行）；DaPars2 读最后一列 `int(fields[-1])`——**未来加列会静默错读**。
3. cfg 内 `Output_result_file` 必须是**相对名**（绝对路径会拼出爆炸目录）。
4. bedgraph 目录层级必须是 `<WORK>/bedgraph/<sample>.bedgraph`（runner 按此拼路径）。
5. slim bed 的 name 是三段 `tid|gid|symbol`——下游 intersect/取 symbol 必须 `split('|')[2]`。
6. GENCODE vM25 的 3'UTR feature 名是 "UTR"。
7. GSE286075 是 dUTP 第二链（ReadsPerGene col4）——已完成层不受影响，复现时勿回退。
8. 三条系统性铁律（§4 末）照常执行；md5/行数门禁习惯照常执行。

### 6.3 集群环境重建清单
- DaPars2：`conda create -n dapars2 python=3.8` + pandas/numpy（试点用 Num_Threads=1 单进程 8.3h/4 样本；全量 12 样本**必须分染色体并行**，见 §7）。
- M4：python ≥3.10 + **pydeseq2==0.5.4（pin 版本！qapa env 的更新版 API 不兼容，design kwarg 报错）** + pandas/numpy/scipy；入口 `scripts/p3_m4_reference_sets.py`（输入路径按集群布局改，输入文件全在仓内 `data\`）。
- FIMO：MEME suite ≥5.5.x（或照搬 meme env）；motif 文件 `data/attract/regulators.motifs.meme`（LF 行尾）。
- intersect：bedtools 2.30+。
- STAR/fastp/samtools：仅当需要重新比对才装（当前不需要）。
