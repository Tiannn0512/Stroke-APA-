### 5.3 P2 统计（SAP v1.1，全量统计前冻结）

```r
pdui_t <- pdui*(1-2*eps)+eps ; eps <- 0.01          # [0,1]→[0.01,0.99]，logit 不发散
logit <- log(pdui_t/(1-pdui_t))
fit  <- lmFit(logit_mat, design)                    # design = ~0 + timepoint（无截距，系数=组均值）
fit  <- eBayes(fit, robust=TRUE, trend=TRUE)        # 抗离群 + 均值方差趋势
fit2 <- eBayes(contrasts.fit(fit, makeContrasts(d1-sham, ..., levels=design)))
# 显著 = 全部 事件×5 contrast 联合 BH padj<0.1 且 |ΔPDUI|≥0.1 且两重复同向
```

## 9. 复现时会踩的坑（勘误与修复总表）

1. **负链错侧**（最大坑）：v5.1 把负链基因丢失段定义在 [PAS→高坐标]。重算必须按 `coordinate_convention.yaml`：负链 distal=[utr_start, PAS)。
2. **PolyASite 域名**：旧 polyasite.ethz.ch 已 NXDOMAIN，用 polyasite.unibas.ch。
3. **edgeR 装不上**：conda R Makeconf 编译器指向不存在文件，sed 改系统 gcc。
4. **library_id 正则**：GSE143531 标题 "2017_545a" 需同时捕获年份与编号组 → library_id "2017545"。
5. **审查表 PDUI 全 NA**：DaPars2 矩阵列是裸样本名；查询键别拼 `sample_PDUI`。
6. **dUTP 链列**：GSE286075 配对 DE 取错链特异性列（col3→col4）会得 6 个 sig 的假象；正确 409。
7. **`A and B or C` 优先级 bug**：一致性计数 579 虚增 → 471。
8. **NTFS/ext4**：fastp/STAR 工作目录放 /mnt/d 慢 3–10 倍；STAR tmp 在 NTFS 直接报错（FIFO）。
9. **bedgraph 必须 `-split`**、深度必须 `-F 0x904`，否则覆盖剖面与归一口径错。
10. **FIMO**：5.5.9 `--thresh` 按 p 值；tsv 末尾 footer 行要跳；序列头含 `::` 会被当 UCSC 区域解析。
11. **random-genome null 无效**：任何 UTR vs 随机基因组=平凡 73 倍富集；必须用长度+GC 匹配的 UTR null（seed 42）。
12. **primer3-py 调用签名**：`design_primers` 需 dict（SEQUENCE_ID/SEQUENCE_TEMPLATE），不是字符串。
13. **Git 大文件**：BAM/FASTQ 先进 `.gitignore`（曾发生 git add -A 卷入 29GB BAM 的未遂提交）。
14. **GSE330741 manifest 矛盾**：651 基因库缺全部候选且符号被 Excel 转日期——不阻断，留待 Koester 2026 supplementary 对账。

## 10. 表述边界（复现者写结论时的红线）

1. 一切 PAS 写作 **"DaPars2-inferred predicted breakpoint within the selected longest annotated terminal 3'UTR reference"**，不写"确认的剪切位点"。
2. 候选 ≠ 验证：结论上限是 **"altered localization potential"（改变定位的潜力）**；PAP 富集只可引文献（Sakers 2017 皮层数据），不可说"我们证明了 Atp2a2 富集在 PAP"。
3. Atp2a2 是 APA 的**靶/受害者**，不是调控子；调控子是 Pabpn1/Qk（证据强度不同，分开表述）。
4. QKI 证据只可写"剪短预测丢失一段 QKI 结合区"；L3 motif 富集为**阴性**（照登）；GSE143531 不支持海马 PAP 富集（照登）；≥2 时间点同向**非独立复现**（共享 sham）。
5. 负结果（终足轴、d21/d60、Cnp/Pea15a 未过阈、Aplp1 总 RNA 塌陷）全部随交付包保留。
