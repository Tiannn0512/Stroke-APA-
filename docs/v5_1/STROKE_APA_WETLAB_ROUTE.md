## 0. 验证逻辑（与干实验证据的对应）

| 干实验结论 | 待湿实验验证的命题 |
|---|---|
| 977 显著 APA 事件（n=2 discovery） | 候选事件缩短在真实星形胶质细胞中可复现（3'RACE/异构体 qPCR） |
| Pabpn1↓ + Qk↓（mRNA 层并发候选） | PABPN1 扰动可重现/回救候选缩短（因果闭环） |
| 剪掉片段含 QKI 结合位点（11 事件） | 该片段确实承载定位/结合功能（reporter 元件删除-回补） |
| PAP 轴定位偏好（rank-shift） | 长/短异构体在突起 vs 胞体的分布差异（定位潜能→实际定位） |
| 定位潜能改变（干实验上限） | 突触旁局部翻译/突触功能改变（第二阶段功能假说） |

## 1. 第一阶段：候选验证（不等机制，直接可做）

**1a. 3'RACE / 异构体特异 qPCR（PAS-switch 验证）**
- 对象：Top5（Ndrg2、Agpat3、Cnp、Pea15a、Fam107a）+ **Atp2a2（三要素案例：PAP 定位 + 缩短 + QKI 结合段丢失，class D——建议与 Ndrg2/Agpat3 并列优先）**；原发小鼠皮层星形胶质细胞（acutely isolated 或 primary culture）+ MCAO 模型或 OGD/R。
- 设计：近端 PAS 与远端 PAS 各设一对引物（坐标取自候选卡：如 Ndrg2 mm10 chr14:51,905,641 近端 / 51,906,142 远端）；3'RACE 用锚定 oligo(dT)+基因特异引物确认断裂点。
- 读出：短/长异构体比例，卒中 vs 假手术、d1/d7/d21。
- 预注册成功标准（建议）：与干实验方向一致（缩短）且至少 3/5 候选复现。

**1b. RNA FISH 预检（可选并入 1a）**：RNAscope 双探针（近端段 vs 远端段）在原位直接看两段信号的比值变化，同步获得空间信息。

## 2. 第二阶段：机制闭环（因果箭头）

**2a. PABPN1 扰动**：
- 原代星形胶质细胞 siRNA/shRNA 敲低 Pabpn1 → 检测 Top5 候选短/长比（应重现缩短）；rescue 回救（应逆转）。
- 同步测 PABPN1 蛋白（WB/IF，核定位）——回应干实验"mRNA≠蛋白"局限。
- QKI 支线：对 11 个 QKI 重叠事件中的 Ndrg2/Agpat3，做 QKI KD 后测异构体比（检验"结合证据"是否带调控功能；L2 语义不允许干实验前预写结论）。

**2b. 长/短 3'UTR reporter 定位实验（定位潜能→实际定位）**：
- 构建：**Atp2a2**（三要素案例，优先）与 Ndrg2、Agpat3 各两版——全长 UTR（含候选丢失段）与截短 UTR（去丢失段），下游荧光/LUC+MS2/MBS 定位示踪。
- 转 primary astrocyte，突起/胞体分割定量（NeuronJ/自定义 mask）。
- 读出：突起/胞体荧光比；预期（按假说）：长 UTR 版富集于突起，短 UTR 版突起分配下降。
- 元件因果加强版：长 UTR 定点删除候选丢失段 vs 短 UTR 回补该段（四构建体，审计 §17 推荐）。

## 3. 第三阶段：隔室与突触（PAP 轴落点）

**3a. smFISH/RNAscope 空间验证**：
- 组织水平：MCAO d1/d7 脑片，Ndrg2/Agpat3 探针 + 星形胶质细胞标志（AQP4/GFAP）+ 突触旁标志（PSD95/Synaptophysin 邻近）+ 血管标志（CD31/lectin，双轨对照）。
- 定量：**突起段信号/胞体信号比值**（不只看总荧光），按距最近突触/血管的距离分箱。

**3b. 突触功能（第二阶段功能假说，仅在定位改变坐实后启动）**：
- 星形胶质细胞特异 AAV（GFAP 启动子）表达候选基因短 UTR 版 → 检查突触形态（spine density）、神经元活动（c-Fos/CA1 场电位）、或共培养微流控突起室。
- 此为功能假说验证，不得在报告干实验部分预写结论。

## 4. 资源受限最小集（审计 §17：三选二）

1. 3'RACE/异构体 qPCR（第一层，必做）；
2. 长/短 UTR reporter 突起定位（机制+定位一箭双雕，强烈建议）；
3. smFISH 突触周空间验证（PAP 轴的直接组织学证据）。
仅做总 RNA qPCR 只能验证表达/APA，不能验证亚细胞定位。

## 5. 阴性结果处理

任一层失败按干实验同款纪律：如实写入报告（如候选不复现 → 事件级发现降级为"公共数据探索性发现"）；不得静默删除或换靶补试。
