# 3prime_end_analysis_plan.md — 独立 3' 端实验的预定义分析方案（v1，2026-09-25）

状态：**预写方案 + 可运行代码框架**。在拿到独立样本数据前不填写任何效应方向或显著性。
配套代码：`analysis_scripts/three_prime_end_analysis.py`（框架，输入格式接口已定义）
样本元数据：`wetlab_metadata_template.tsv`

## 1. 实验设计要求（交实验团队）

- **独立动物**：sham 与卒中（MCAO）各自独立取材；**主要比较 = day 7 vs sham**（预先固定），day 3 为次要时间点。发现队列的 sham 不可复用。
- **脑区固定**：与发现队列一致的皮层区；每只动物记录取材亚区与半球（同侧/对侧，或双侧统一）。
- **样本量**：由预实验（pilot ≥3 组/组）的 L/S 比例变异、主要终点（ΔL 占比）与预定效应量计算；**技术孔与克隆/读段数不算生物学重复**，小鼠是唯一生物学单位。
- **方法**：3'RACE（确认位点）+ 有分子计数能力的靶向 3' 端测序（估计比例）。比例**不得**从凝胶条带强度推断。
- **对照**：每批 no-RT、无模板对照；内部引发检查（M 端 122456339 下游 A50%/run5 中风险，必查：polyA 接合读段必须跨 RNA–poly(A) 边界）。
- **引物**：使用 `assay_design_verified.tsv` 的 verified 行（outer/nested GSP v2、qPCR_total、distal、long_junction_v2、J_S、J_L）；deprecated 行不得订购。实验负责人终审后下单。

## 2. 读段 → 末端的判定规则（预先写定）

1. **RNA–poly(A) 接合要求**：有效分子 = 读段 3' 端与 poly(A)/adapter 接口处无模板碱基（non-templated） 且比对末端落在候选位点 ±50bp；只有这类分子才能宣告 3' 末端坐标。
2. **末端坐标**：接合点前最后一个模板碱基的基因组坐标（BED 0-based，mm10/GRCm38+GENCODE vM25 报告；如换参考需给 liftover 链）。
3. **分子归属（按结构事实，见 Atp2a2_transcript_structure.tsv）**：
   - L 分子：读段跨 L 独有接头(donor122455892→acceptor122454304) 或 3' 端位于终端外显子且含 L 独有段序列
   - S 分子：读段跨 S 独有接头(donor122457302→acceptor122454304)
   - M 分子：3' 端位于 122456339±50 且不含 L/S 接头
   - **不能唯一归属的分子**：计入 `ambiguous`，不删除；报告 ambiguous 比例（预期主要来自 L/M 共有区的截断分子），主分析用唯一归属，敏感性分析给含 ambiguous 的区间。
4. **每只动物输出**（three_prime_end_analysis.py）：各位点末端坐标分布、有效分子数、L:M:S 比例 + Beta 二项/自助置信区间；组间效应 = 动物级 ΔL 占比 + 置信区间（day7 主比较，day3 次要）。
5. **克隆处理**：UMI 或分子计数去重；无 UMI 时以 (起点,末端,长度) 三元组去重并在局限中声明。
6. **多重比较**：位点层面预定义 3 个主位点（L/S/M 端），不做事后全表扫描；次级候选位点（122453580/122453643/122453690/122453873/122456938）只做探索性报告。

## 3. 通过/失败判据（预先固定）

- Gate B 通过：≥2 只/组、每只 ≥200 有效分子、接合读段支持的末端与 PolyASite/注释端重合、L:S 比例的组间差可估计
- Gate B 失败 → 改写为"剪接/加工问题"（转用 long_junction_v2 + J_S 的 RNA 证据框架）或按任务书启动备靶审查（本轮未触发：Atp2a2 未失格）
