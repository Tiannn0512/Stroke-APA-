# regulatory_mechanism_plan.md — 序列与调控机制实验的预定义方案（v1，2026-09-25）

状态：**预写方案**。前置条件：Gate C（空间分布）通过后才启动。QKI peak/motif/PABPN1 表达线索只能用于假设筛选，不写成因果结果。

## 1. 序列必要性（3'UTR 片段）

- 构建匹配的 L/S 3'UTR reporter（双荧光，控制表达量与构造差异）；L 远端片段（含 L 独有段 447bp + 终端外显子 UTR）删除/回补
- 候选顺式元件突变：预测近端 PAS 区（重锚定后为 122456339 簇，AATAAA@-31）、QKI peak（122454200-122454250，FDR 1.04e-5，位于 L 终端外显子 UTR——注意在 L 的内含子化 UTR 内，S/M 无此序列）
- 读出：reporter 的 3' 端选择（3' 端测序读出，不用荧光比例推 APA）+ 亚细胞定位（RNA 斑点）

## 2. 调控因子扰动

- QKI 或 PABPN1 扰动（敲低/过表达）须**分别检验**：① 对内源 Atp2a2 真实 3' 端选择的影响（3' 端测序）；② 对版本 PAP 定位的影响（Gate C 范式的探针）
- 设置救援实验（rescue：扰动 + cDNA/片段回补）才能主张因果
- 主要对照：非靶 gRNA/无关蛋白；阳性对照用已知 QKI 靶（文献先例，novelty_overlap.tsv）

## 3. 判定

- Gate D 通过 = 片段干预与调控因子扰动**分别**支持对应因果环节；否则只报告已获实验支持的现象，不合并叙事。
