## 1. 探针设计（RNAscope/smFISH，按真实转录本结构）

| 探针 | 靶序列 | 覆盖版本 | 依据 |
|---|---|---|---|
| common（总量） | qPCR_total 区（122491680-122491785 外显子）或 3' 端共有 CDS 区多 Z 探针 | L+S+M(+2 次要) | assay_design_verified.tsv |
| L 特异 | L 独有段 122455892-122456339（447bp，多 Z 对）或 L 接头/J_L 序列 | 仅 L | 唯一序列段 |
| S 探断 | 跨 S 接头序列（J_S 24mer 邻域） | 仅 S 剪接型 | 唯一接头 |
| M | 无独有序列——用 common − L − S 推断，或 3' 端位探针（待 3'RACE 后定） | M | 结构决定 |

**短版（S）检测的校正要求**：S 无独有序列，单探针不可行；双探针推断（common − L）必须做检出效率校正，且校正系数需在细胞样本上用已知混合物/独立方法验证后才能用于定位结论。

## 2. PAP/胞体判定标准（预先固定）

- **PAP**：EGFP/标记的星形胶质细胞突起段，距最近突触（synaptophysin/PSD95 免疫）≤2 μm，直径 <1 μm，**距胞体 >15 μm**，偏离血管周围（GFAP+ 终足与血管 GBM 标记以 CD31/IB4 定义）→ 单独排除血管周围终足，不计入 PAP 也不计入胞体
- **胞体**：DAPI 邻域（≤3 μm）且满足上述排除
- 排除：成像批次离群（z>3 MAD）、探针检出率异常的切片、形态崩坏细胞——排除规则写进脚本，不得事后挑选

## 3. 统计模型（主检验预先固定）

- 主检验：**卒中状态（day7 vs sham）× 区室（PAP vs 胞体）对版本相对分布（L 占比，logit 变换）的交互作用**
- 模型：混合效应 `logit(L%) ~ stroke * compartment + total_expression + (1|animal) + (1|batch)`；细胞与 RNA 点**嵌套在动物内**，动物是生物学单位；小样本不以细胞数冒充 n
- 敏感性：动物级汇总重采样；报告效应量 + 95% CI；协变量检查：总表达、突起形态（长度/面积）、探针检出率
- 影像元数据逐动物记录：脑区、批次、细胞数、PAP 面积/体积、点数（wetlab_metadata_template.tsv）

## 4. 通过/失败判据（预先固定）

- Gate C 通过：交互作用方向一致且 CI 不跨零（或贝叶斯等效判据），并排除上述混杂
- Gate C 失败 → 不主张"卒中诱导 APA 改变 PAP 定位"；报告已有的表达层面结果
