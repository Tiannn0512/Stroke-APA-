# GSE143531 重分析（任务 A，2026-09-23）

> 触发：预审指出 v1 分析以**未归一化原始计数**直接相除计算 log2(PAP/Full)，
> 而 PAP 文库总量仅约为 Full 的 1/10——深度差主导了旧比值。本重分析以 edgeR TMM
> 归一化、以生物学文库为单位重算，并审计 PAP 基因列表来源。

## 方法（对应预定的操作步骤）

1. 样本表：48 文件 = 6 生物学文库 × 8 技术重复（series matrix 解析；library_id 与
   文件名前缀一致，如 2017_545a → 文件 2017545a）。字段：GSM、library_id、cell_part、
   technical_rep、pool_size（PAP=2 只/库，Full=1 只/库，据 Mazaré 2020 methods）、
   biological_unit、paired_status=unpaired（C1/C2/C3 标签不足以证明两分区取自同鼠，
   且池构成不同）。
2. 技术重复合并：8 文件按 gene ID 求和 → 6 列计数矩阵（47,643 基因）。
3. 统计单位：**文库**（每分区 3 个），主模型为**未配对** 3 PAP vs 3 Full。
4. edgeR（4.0.16，R 4.3.3）：filterByExpr → TMM → estimateDisp(robust) →
   glmQLFit(robust) → glmQLFTest(PAP−Full)。日志与版本见
   `logs/p4_1_gse143531_v2.log`（本轮在 WSL rlimma env 编译 edgeR 时将 conda R 的
   Makeconf 编译器改为系统 gcc 后安装成功）。

## 结论（如实）

1. **归一化后结论不变、数值大变**：Atp2a2 从未归一化的 −3.27 变为归一化 −0.273
   （百分位 54.0%→55.4%）——证实 v1 的绝对数值被深度差主导，但"**Atp2a2 在健康海马
   不偏向 PAP**"这一定性结论经得起归一化检验（FDR=0.683，与背景无差异）。
2. **候选均无 PAP 富集**（归一化后无一个 FDR<0.05）；Plec 仍是唯一正向信号
   （log2FC=+3.86，FDR=0.0595，百分位 96.6%）且在皮层 GSE74456 中也最强富集
   （log2FC=+4.41）——两脑区一致的 PAP 富集基因，但其卒中 APA 事件证据薄（见 P3）。
3. 定位先验的使用边界不变：该数据集只承担 gene-level 可测性与描述性排序
   （exploratory, n=3 文库/组），不判定"富集"与否的机制结论，也不进入空间假设的
   证明链。
4. 每组 3 个文库为小样本，FDR 值仅供排序参考；结果标记为 **gene-level exploratory
   evidence**。
